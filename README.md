# Telecomopen

خريطة تفاعلية لمواقع خلايا الاتصالات المرصودة في السودان، باستخدام خرائط OpenStreetMap وبيانات OpenCellID. النقاط تمثل خلايا مرصودة وليست حدودًا مضمونة للتغطية أو جودة الإشارة.

## التشغيل

1. أنشئ مفتاح API من OpenCellID.
2. انسخ `.env.example` إلى `.env` وضع المفتاح في `OPENCELLID_API_KEY`.
3. استخدم Node.js 18 أو أحدث، وشغّل `npm start` ثم افتح `http://localhost:3000`.

لا يحتاج المشروع إلى تثبيت حزم npm. يسمح المتصفح بتحديد الموقع تلقائيًا بعد موافقتك، وإلا تبدأ الخريطة من الخرطوم. لا تضع مفتاح API في ملفات الواجهة.

تُنسب بيانات الخريطة إلى OpenStreetMap. بيانات الخلايا من OpenCellID ومرخصة بموجب [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). تعرض كل عملية بحث حتى 50 خلية من نطاق لا يتجاوز 4 كم². حد الاستخدام اليومي 1,000 طلب لكل مفتاح API.

## الاختبارات

شغّل `npm test` للتحقق من مسارات الخادم والتحقق من نطاقات البحث.
